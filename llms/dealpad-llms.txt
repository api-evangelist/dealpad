# Dealpad

> Dealpad (dealpad Ltd) is an AI-powered buyer-enablement and digital-sales-room platform for B2B sales teams. It centralizes the buyer/seller relationship into shared digital sales rooms, mutual action plans, and a content repository, layering "Sales Mind AI" predictive insight over the deal to help sellers progress complex, multi-stakeholder opportunities. Dealpad integrates with Salesforce, HubSpot, and Zoho CRMs. **Dealpad publishes no public developer API, no OpenAPI/AsyncAPI/GraphQL specification, no developer portal, and no SDKs.** API access is sold as an enterprise-tier contract feature, not as a self-serve developer product. This profile is maintained independently by the API Evangelist network and is not affiliated with or endorsed by Dealpad.

## APIs
- **None published.** Dealpad exposes no public developer API, no OpenAPI/Swagger definition, no GraphQL SDL, no AsyncAPI document, no webhook catalog, no MCP server, and no A2A agent card. There is no developer portal, no API reference, no getting-started guide, and no public support channel for developers.
- API access is a **paid enterprise feature, not a public product**: "API integrations" and "Custom CRM integration" appear only on the Large tier (from $2,999/month, 8+ seats) of the published pricing page, behind a "Talk to our Enterprise Team" gate. The Small ($499/month) and Growing ($799/month) tiers do not include API access.
- A private, session-authenticated application backend does exist behind the product — it is namespaced under a `/apiv1/` URI-path prefix, returns a `dealpad-version` response header, and answers anonymous callers with HTTP 403. It is the product's own internal backend, not a documented integration surface, and there is no published contract for it.

## Specs
- No machine-readable specification of any kind is published. Probed and confirmed absent: `/openapi.json`, `/openapi.yaml`, `/swagger.json`, `/v3/api-docs`, `/api-docs`, `/redoc`, `/graphql` introspection, and `/llms.txt` — on the marketing host, the API host, and the application host.

## Discovery
- No `/.well-known/` document is served on any Dealpad host. See `well-known/dealpad-well-known.yml` for the full probe record — and note the warning it carries: `*.dealpad.io` is a wildcard DNS catch-all that answers HTTP 200 with a single-page-app HTML shell for hostnames that do not exist, so a 200 on a `/.well-known/` path there is a false positive, not a document.

## Plans
- Small — from $499/month, up to 3 seats, unlimited buyers and rooms, content repository, collaboration, email support. No API access.
- Growing — from $799/month, 4-7 seats, adds analytics, CRM integration, SalesMind AI, playbooks & templates, live chat support. No API access.
- Large — from $2,999/month, 8+ seats, adds custom CRM integration, white-labeled domain, dedicated customer success, phone support, and **API integrations**.
- A 14-day free trial is advertised, but behind a lead-capture form; there is no self-serve sign-up or checkout.
